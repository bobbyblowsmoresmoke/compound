# SLS-0015 Identity

Status: Accepted
Version: 1.0
Depends On: SLS-0003

## Purpose

This specification defines identity rules for Compound domain objects.

## ID prefixes

Specimen: SPM
Formula: FRM
Catalyst: CAT
Assay: ASS
Reagent: RGT
Pipeline Run: RUN
Experiment: EXP
Notebook Entry: NBK
Distillation: DST

## Rule

No primary domain object is anonymous.

Every durable object must have a stable ID, revision where applicable, and provenance.
