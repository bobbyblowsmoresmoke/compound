# SLS-0050 Repository Layout

Status: Draft
Version: 0.1

## Purpose

This specification defines the intended repository layout.

## Layout

corpus/ contains the authoritative specifications.

experiments/ contains active or completed research questions.

formula/ contains Formula packs and examples.

samples/ contains simple example inputs.

specimens/ contains normalized examples and fixtures.

assays/ contains Assay definitions and expected findings.

reagents/ contains adapters and exporters.

catalysts/ contains provider and local model adapters.

notebook/ contains generated local experiment history and should usually be ignored by source control except examples.

output/ contains generated local outputs and should usually be ignored by source control except examples.
