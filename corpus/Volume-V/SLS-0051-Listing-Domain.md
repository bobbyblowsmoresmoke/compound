# SLS-0051 Listing Domain

Status: Draft
Version: 0.1

## Purpose

This specification defines the first artifact domain: marketplace listings.

## Required listing concerns

Title.
Description.
Price.
Condition.
Category.
Images.
Shipping information.
Dimensions.
Weight.
Brand.
Material.
Trust signals.
Return policy.
Keywords.

## Rule

Listing-specific behavior must not leak into the artifact refinement core.
