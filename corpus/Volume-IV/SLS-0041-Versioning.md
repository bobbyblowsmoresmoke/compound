# SLS-0041 Versioning

Status: Draft
Version: 0.1

## Purpose

This specification defines versioning rules.

## Versioned objects

Corpus specifications.
Formulas.
Catalysts.
Assay packs.
Reagents.
Specimen revisions.
Notebook entries.
Compound releases.

## Rule

Versioning exists to support repeatability.

If an output cannot identify the versions involved in its creation, the output is incomplete.
