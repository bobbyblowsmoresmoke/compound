# SLS-0038 Configuration

Status: Draft
Version: 0.1

## Purpose

This specification defines configuration behavior.

## Rules

Configuration must be local-first.
Defaults must be safe.
Configuration must be inspectable.
Configuration must not silently change pipeline behavior.

## Initial configuration domains

Active Catalyst.
Formula directories.
Output directory.
Notebook directory.
Assay settings.
Offline mode.
