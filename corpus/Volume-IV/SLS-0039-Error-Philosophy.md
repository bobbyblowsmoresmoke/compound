# SLS-0039 Error Philosophy

Status: Draft
Version: 0.1

## Purpose

This specification defines how Compound fails.

## Rule

Compound fails clearly.

Silent failure is forbidden.

## Error output must include

What failed.
Why it failed.
What object was involved.
Whether the original Specimen was preserved.
What the user can inspect next.

## Example

Assay failed.

Finding: Missing shipping information.

Recommendation: Add handling time, shipping method, and return policy.
