# SLS-0033 Release Process

Status: Draft
Version: 0.1

## Purpose

This specification defines how Compound releases are prepared.

## Release rule

A release must not ship unless the Corpus, implementation, tests, and examples agree.

## Release names

Compound releases use scientific codenames.

0.1 Carbon
0.2 Copper
0.3 Cobalt
0.4 Titanium
0.5 Argon
1.0 Helix

## Required release checks

Corpus consistency check.
Golden Specimen regression check.
Core test suite.
No-network baseline test.
CLI smoke test.
Notebook replay test where available.
