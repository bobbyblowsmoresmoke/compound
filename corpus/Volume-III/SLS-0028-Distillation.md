# SLS-0028 Distillation

Status: Draft
Version: 0.1

## Purpose

This specification defines Distillation.

## Definition

Distillation is the process of generating local output artifacts from an accepted Specimen revision.

## Outputs

Initial output formats should include Markdown, JSON, and plain text.

## Rule

Distillation does not decide correctness.

Correctness is evaluated by Assays and accepted by the user or caller.

## Metadata

Every Distillation must record source Specimen revision, output format, Reagent where applicable, timestamp, and Notebook entry ID.
