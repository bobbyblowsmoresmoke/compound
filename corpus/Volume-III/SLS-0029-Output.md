# SLS-0029 Output

Status: Draft
Version: 0.1

## Purpose

This specification defines Compound outputs.

## Output principles

Outputs are local.

Outputs are inspectable.

Outputs preserve provenance.

Outputs do not overwrite source artifacts.

## Initial output targets

Markdown preview.
JSON package.
Plain text listing.
Assay report.
Notebook entry.

## Rule

An output without provenance is incomplete.
