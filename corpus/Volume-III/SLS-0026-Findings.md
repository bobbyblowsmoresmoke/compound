# SLS-0026 Findings

Status: Accepted
Version: 1.0

## Purpose

This specification defines the Finding object.

## Definition

A Finding is a structured diagnostic statement produced by an Assay or refinement process.

## Required fields

Code.
Severity.
Domain.
Evidence.
Recommendation.
Confidence.
Source object.
Related Formula where applicable.
Related Assay where applicable.

## Severity

Info.
Warning.
Error.
Blocking.

## Rule

Free-form criticism is not enough.

Every actionable issue should become a Finding.
